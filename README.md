# Джарвис — локальный голосовой ассистент

Полностью локальный voice-ассистент: распознавание речи, LLM с function calling
и синтез речи — всё работает на этой машине, без облака.

## Стек
- **STT:** faster-whisper (`medium`, CPU, int8)
- **LLM:** gpt-oss:20b через Ollama, streaming + tool calling
- **TTS:** Silero (`v4_ru`, голос `eugene`), потоковая озвучка по предложениям

## Первый запуск
```bash
ollama serve
```
(в отдельном терминале, если ещё не запущен)

```bash
venv\Scripts\python main.py
```

При первом запуске Silero-модель скачается через torch.hub (нужен интернет один раз,
дальше кэшируется локально в `%USERPROFILE%\.cache\torch\hub`).

## Как пользоваться
- Нажми Enter — начинается запись с микрофона.
- Говори.
- Нажми Enter ещё раз — запись останавливается, идёт распознавание и ответ.
- Ctrl+C — выход.

## Открытие приложений
Список разрешённых приложений — в `tools.py` (`APPS`). Это осознанное ограничение:
LLM может запускать только то, что явно в белом списке, а не произвольные команды.
Чтобы добавить приложение — впиши путь в словарь `APPS`.

## Известные ограничения прототипа
- Push-to-talk (Enter/Enter), а не voice activity detection — для VAD и «вечно слушающего»
  режима нужна отдельная итерация.
- STT/LLM/TTS работают последовательно по фразе, не внахлёст между репликами пользователя.
- gpt-oss:20b — модель на английском окружении с сильным function calling; если качество
  русского в ответах не устроит, следующий кандидат на замену — Qwen3.5-9B.
