# Дизайн интерфейса Гоги

Исходники концепт-макета GUI (Claude Design canvas). Три экрана:
`Main.dc.html` — главный дашборд с голосовым орбом и журналом диалога,
`Commands.dc.html` — быстрые команды и файловый браузер (Desktop Commander),
`Settings.dc.html` — голосовые профили и выбор модели.

Опубликованная версия для просмотра:
https://claude.ai/code/artifact/3ccaf8c0-714c-4fe8-b011-a4a8685684ac

## Статус
Направление дизайна утверждено (тёмный HUD, янтарный акцент, персистентная
навигация слева, крупный анимированный орб). Следующий шаг — выбрать
технологию для реализации (обсуждали Python + pywebview/Tauri поверх
существующего бэкенда) и решить, как упростить бэкенд под нагрузку GUI.
