# Дизайн интерфейса Гоги

Исходники концепт-макета GUI (Claude Design canvas). Три экрана:
`Main.dc.html` — главный дашборд с голосовым орбом и журналом диалога,
`Commands.dc.html` — быстрые команды и файловый браузер (Desktop Commander),
`Settings.dc.html` — голосовые профили и выбор модели.

Опубликованная версия для просмотра:
https://claude.ai/code/artifact/3ccaf8c0-714c-4fe8-b011-a4a8685684ac

## Статус
Реализовано. Направление дизайна (тёмный HUD, янтарный акцент, персистентная
навигация слева) легло в основу `gui.py` + `gui/index.html` (pywebview) —
эти `.dc.html`-макеты нельзя было использовать напрямую как веб-страницу
(это шаблоны редактора Claude Design canvas, не обычный HTML/JS), поэтому
интерфейс переписан с нуля с той же визуальной идеей, но с реальным JS,
подключённым к бэкенду (`assistant.py`, `tools.py`) вместо статичных
плейсхолдеров.

По ходу разработки основным интерфейсом стал терминальный (`tui.py`,
Textual) — тот же набор из трёх экранов (Главный/Команды/Настройки), но
без окна браузера, в духе терминальных клиентов вроде Claude Code. GUI на
pywebview остаётся как альтернатива для тех, кто предпочитает мышь и
отдельное окно.
